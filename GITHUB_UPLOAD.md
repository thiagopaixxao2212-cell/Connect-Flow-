# Como subir este pacote pelo navegador do GitHub

1. Extraia o arquivo ZIP no seu computador.
2. Abra o repositório privado `Connect-Flow-` no GitHub.
3. Clique em **uploading an existing file / enviando um arquivo existente**.
4. Abra a pasta extraída `Connect-Flow-GitHub`.
5. Selecione **todo o conteúdo dentro da pasta** e arraste para o GitHub.
6. Confirme que aparecem `index.html`, `public`, `supabase`, `docs`, `.gitignore`, `.env.example`, `README.md` e `vercel.json`.
7. Em **Commit changes**, use a mensagem: `Initial ConnectFlow Digital snapshot`.
8. Clique em **Commit changes**.

Não envie o ZIP dentro do repositório; envie os arquivos extraídos.
